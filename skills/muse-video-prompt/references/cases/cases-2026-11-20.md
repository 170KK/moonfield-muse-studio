# 案例卡：2026-11-20 月域画布六段式 + 尾帧接力 3 段连续镜头实测

## 江南古镇清晨漫步 18 秒（3 段连续镜头）
- **提示词要点**：
  - 严格采用六段式结构（`[6秒 / 9:16]` + `人物：` + `场景：` + `分时节拍：` + `镜头语言：` + `声音：` + `限制：`）。
  - **人物逐字复用**：`人物：林晚，24岁东亚年轻女性，黑长直发披肩，穿米白色针织开衫内搭浅灰T恤、深蓝牛仔长裤，背棕色小号斜挎帆布包。` 在 S01/S02/S03 全片一字不改。
  - **段首接续声明**：S02/S03 段首加入`本段为 18 秒短片的第 K 段（X-Y 秒），延续上一段尾帧与参考图的同一人物/场景/光线/质感，人物服装发型面容严格保持一致。`，并配合月域画布真实解码尾帧（`first_last`）接力。
- **结果**：
  - S01（95.2s，1.26 MB）、S02（215.2s，1.68 MB）、S03（90.1s，4.73 MB）全部一次生成成功，均为 `720×1280` 竖屏 6.0 秒。
  - **吃进项**：9:16 竖屏、江南古镇青石板/马头墙/清晨薄雾暖光、米白针织开衫、深蓝牛仔裤、棕色斜挎包、S01 停木窗→S02 走向石拱桥→S03 扶石桥栏杆望河面柳影，全程无穿模、无多余路人、无文字水印。
  - **接缝 PSNR 验收（阈值 ≥ 25.0 dB）**：
    - `S01 → S02`：`34.362 dB`（通过）
    - `S02 → S03`：`30.940 dB`（通过）
- **偏差与原因推测**：
  - **偏差项**：S01-f1 为披肩长发，S01-last 侧身抬头时模型将其束成了低马尾（S02/S03 延续了该低马尾，三段内部连贯但与 S01 开头细节有微变）。
  - **原因推测**：“黑长直发披肩”未加“不扎马尾、无发圈”强约束，人物侧身转身时模型倾向于收拢长发。
- **教训**：
  - 发型若要求全程披散，需在「人物：」或「限制：」里显式写死“全程自然披散，不扎马尾、不绑发”。
  - 六段式结构 + 逐字复用人物描述 + 真实尾帧接力下，3 段连续镜头接缝 PSNR 稳定在 30–34 dB 以上，服装、包袋、光影和空间连续性极稳。

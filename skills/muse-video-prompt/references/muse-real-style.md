# Muse 真人质感与精简提示词规范（去 AI 感核心原则）

编写 Muse 真人/影视提示词时，**少即是多**：
- **锚定「真人实拍照片 / 电影剧照」品类**：避免「三视图、设定稿、概念图、表情矩阵」等会把模型拉向插画/游戏CG的词；角色资产只生成**一张单人正面实拍定妆照**，把算力全部集中在这一张脸上，真实感与一致性最好。
- **减少干扰词，留白给真实感**：不要一次塞几十个琐碎约束，否则模型为了“交差”会把画面抹平成塑料平均脸。只保留**核心身份 + 核心服装 + 场景光线 + 景别动作 + 少量真实质感词**。

## 一、通用七要素结构模板

每段分镜 / 单段提示词尽量覆盖以下 7 个维度：
1. **人物**：具体年龄段 + 体型特征 + 发型发质 + 自然妆容 + 具体神态/微表情；写明「五官可辨但不处处锐利、自然皮肤纹理与通透肤色」，避免过度磨皮与塑料反光。
2. **服装**：具体单品 + 颜色 + 面料质感（如罗纹棉、薄透丝袜、哑光旧布）+ 版型剪裁 + 物理垂坠/褶皱/随风微扬；明确「服装全程不变、不缺件不变形」。
3. **场景**：室内/室外明确空间 + 前/中/后景具体物件与材质（如浅色木地板、深灰窗帘、浅米色石材、几何线条）+ 背景轻微虚化；明确「场景固定」。
4. **光线**：主光方向 + 光质软硬（如「室内暖色柔光正面打 / 柔和漫射自然光」）+ 面部提亮与暗部颗粒、面料/皮肤自然反光。
5. **机位与光学**：画幅（`9:16` 竖屏 / `16:9` 横屏）+ 具体景别（全身 / 中近景腰腹以上 / 大腿以上）+ 视角（眼平视角 / 手持手机自拍视角）+ 焦段/移轴（如 `85mm` 长焦、轻微移轴、浅景深）+ 具体运镜（如「一镜到底，先全身 2 秒 → 缓慢推近半身 8 秒 → 拉回全身」）。
6. **动作时间线**：起始姿态 → 关键连续动作（包含重心摆动、呼吸起伏、抬手/转身等细节与物理惯性）→ 结束姿态。
7. **真实质感与避坑约束**：
   - **去 AI 感（保留真实摄影瑕疵）**：保留「轻微动态拖影、短暂失焦、暗部细小颗粒与少量彩噪、随呼吸自然起伏、轻微手持晃动」；**避免**写「强稳定、全程处处锐利、无瑕皮肤」。
   - **一致性与防跑偏**：写明「全程同一人物、服装全程不变、场景固定；无文字水印、无任何文字、无 logo、无多余路人」。

## 二、常见风格参考范例

### 1. 自拍风（竖屏 9:16，720p，10 秒）
- **适用关键词**：手机视角、手持晃动、呼吸起伏、动态拖影、短暂失焦、暗部颗粒与少量彩噪、全程自带音频。
- **示例**：开场中近景（腰腹到上半身），白短袖罗纹深 U 领，随呼吸自然起伏；她左右摆动重心、轻微甩手，手机先放低再抬至自拍；画面保留自然动态拖影与短暂失焦，美颜柔和、肤色通透，暗部有细小颗粒与少量彩噪；720p，竖屏 9:16，无文字水印，全程自带音频。

### 2. 试衣间慢舞 / 室内生活感（竖屏 9:16，720p，10 秒）
- **适用关键词**：全身→推近→拉回、暖色柔光、自然反光、一镜到底、不戴口罩不拿手机。
- **示例**：人物：全程同一人，成年女性，长棕直发，妆容自然，不戴口罩、不拿手机；服装：深蓝无袖高领紧身上衣 + 灰细条纹包臀短裙 + 黑薄透连裤袜 + 黑尖头铆钉高跟鞋，全程完整；场景：室内试衣间，浅色木地板 + 深灰窗帘，右侧黑购物篮，镜面干净，背景轻微虚化；光线：室内暖色柔光正面打，皮肤明亮，裙子与丝袜自然反光；机位：9:16 竖屏，一镜到底，先全身 2 秒 → 缓慢推近半身 8 秒 → 拉回全身，镜头平稳；风格：自然慢舞，动作流畅，表情放松，无文字水印，720p。

### 3. 时尚 Editorial（竖屏 9:16 / 横屏 16:9，8–12 秒）
- **适用关键词**：85mm 长焦、眼平视角、轻微移轴、浅景深、柔和漫射室内光、风感与身体张力。
- **示例**：人物：20 岁出头，沙漏型身材，四肢线条紧致，皮肤通透，表情自信，直视镜头；服装：宽松白衬衫（前开襟、自然垂坠、卷起袖口），随风微扬；场景：高格调建筑空间，浅米色石材 + 几何线条，背景简洁；光线：柔和漫射室内光，正面提亮面部，浅景深；机位：竖屏 9:16，中近景（大腿以上），眼平视角，85mm 长焦，轻微移轴；风格：时尚生活 editorial，动态风，自然风，无文字水印，720p。

## 三、常见坑与避坑词对照
- **防文字/水印**：必须写「无文字水印、无任何文字、无 logo」。
- **防僵硬假稳定**：用「镜头平稳、轻微晃动、保留自然动态拖影与短暂失焦」，不用「强稳定、全程锐利」。
- **防五官塑料锐化**：用「五官可辨但不处处锐利、自然皮肤质感、暗部轻微颗粒与少量彩噪」。
- **防换装换人**：用「全程同一人物、服装全程不变、场景固定」。
